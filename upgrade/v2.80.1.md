# MainNet v2.80.0 -> v2.80.1 Upgrade Instructions

The following instructions will allow patch your node from v2.80.0 to v2.80.1 to fix the chain halt.

**:exclamation: Run these steps in sequence, do not skip any steps! :exclamation:**

1. Download and upgrade using the v2.80.1 release bundle.

    The [v2.80.1 release bundle](https://github.com/Switcheo/carbon-bootstrap/releases/tag/v2.80.1) contains v2.80.1 binaries.

    We will be placing v2.80.1 binaries (`carbond`) in the `cosmovisor/upgrades/v2.80.0` directory.

    ```bash
    VERSION=2.80.1
    MINOR=2.80.0
    NETWORK=mainnet
    FILE=carbond${VERSION}-${NETWORK}.linux-$(dpkg --print-architecture).tar.gz
    wget https://github.com/Switcheo/carbon-bootstrap/releases/download/v${VERSION}/${FILE}
    tar -xvf ${FILE}
    rm ${FILE}
    sudo service carbond stop
    mv carbond ~/.carbon/cosmovisor/upgrades/v${MINOR}/bin/carbond
    sudo service carbond start
    ```

2. Check that you have configured the right versions of `carbond`.

    Ensure that you have the right binaries installed under the `cosmovisor` directory:

    ```bash
    openssl sha256 ~/.carbon/cosmovisor/upgrades/v2.80.0/bin/carbond
    # arm64 9f38e60f3af43779aff75efec807134f9ed82713da2095f3090afa49a9c3bf50
    # amd64 4ebacb08cf767eda29254d1a3ab9d31edc7478d30276ba5ddda719c7d0fc06bc
    ```
