# MainNet v2.82.0 -> v2.82.1 Upgrade Instructions

The following instructions will allow patch your node from v2.82.0 to v2.82.1 to fix the chain halt.

**:exclamation: Run these steps in sequence, do not skip any steps! :exclamation:**

1. Download and upgrade using the v2.82.1 release bundle.

    The [v2.82.1 release bundle](https://github.com/Switcheo/carbon-bootstrap/releases/tag/v2.82.1) contains v2.80.1 binaries.

    We will be placing v2.82.1 binaries (`carbond`) in the `cosmovisor/upgrades/v2.82.0` directory.

    ```bash
    VERSION=2.82.1
    MINOR=2.82.0
    NETWORK=mainnet
    FILE=carbond${VERSION}-${NETWORK}.linux-$(dpkg --print-architecture).tar.gz
    wget https://github.com/Switcheo/carbon-bootstrap/releases/download/v${VERSION}/${FILE}
    tar -xvf ${FILE}
    rm ${FILE}
    sudo service carbond stop
    mv carbond ~/.carbon/cosmovisor/upgrades/v${MINOR}/bin/carbond
    sudo service carbond start
    ```

2. Check that you have configured the right versions of `carbond`.

    Ensure that you have the right binaries installed under the `cosmovisor` directory:

    ```bash
    openssl sha256 ~/.carbon/cosmovisor/upgrades/v2.82.0/bin/carbond
    # arm64 aa4adad6584d9ef12c07c92f43d36e9ec33b83cb3276907b732820ae66658f8a
    # amd64 d8b7f5d018881a68300fd28eeb50b342369361001f79ce23de5755f94eedce88
    ```
