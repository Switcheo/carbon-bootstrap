# MainNet v2.84.0 -> v2.84.1 Upgrade Instructions

The following instructions will allow patch your node from v2.84.0 to v2.84.1 to fix the chain halt.

**:exclamation: Run these steps in sequence, do not skip any steps! :exclamation:**

1. Download and upgrade using the v2.84.1 release bundle.

    The [v2.84.1 release bundle](https://github.com/Switcheo/carbon-bootstrap/releases/tag/v2.84.1) contains v2.84.1 binaries.

    We will be placing v2.84.1 binaries (`carbond`) in the `cosmovisor/upgrades/v2.84.0` directory.

    ```bash
    VERSION=2.84.1
    MINOR=2.84.0
    NETWORK=mainnet
    FILE=carbond${VERSION}-${NETWORK}.linux-$(dpkg --print-architecture).tar.gz
    wget https://github.com/Switcheo/carbon-bootstrap/releases/download/v${VERSION}/${FILE}
    tar -xvf ${FILE}
    rm ${FILE}
    sudo service carbond stop
    mv carbond ~/.carbon/cosmovisor/upgrades/v${MINOR}/bin/carbond
    sudo service carbond start
    ```

2. Check that you have configured the right versions of `carbond`.

    Ensure that you have the right binaries installed under the `cosmovisor` directory:

    ```bash
    openssl sha256 ~/.carbon/cosmovisor/upgrades/v2.84.0/bin/carbond
    # arm64 dc275c3d0808618dab3a80cb97100a017c8b3892901a085d35069c1dc1315fb7
    # amd64 c299bbc686c2fee3646ade39a8525e93b6b3d0c36d6a15f79f1b563e99e84bc2
    ```
